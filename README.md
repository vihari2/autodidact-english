# 🌟 Self-Taught English Language Framework

> A practical, self-study methodology designed to build English fluency from intermediate (A2/B1) to independent upper-intermediate (B2+) using free digital tools, structured routines, and modular guides.

---

## 🌟 About The Project

This repository documents my personal self-taught framework for learning English. Instead of relying solely on traditional language schools, this system combines structured coursebook study with daily active output (speaking and writing) powered by modern tools like ChatGPT, Google Meet, and Notion.

Using this exact framework, I progressed from **A2 to B2 (53/100 on the EF SET exam)** with **C1 reading proficiency**.

---

## 🌟 The Method Stack

This system integrates four main pillars to cover all core language skills (*Reading, Listening, Writing, Speaking*):

| Tool / Resource | Purpose & Application |
| :--- | :--- |
| **Coursebooks & YouTube** | Structured grammar, vocabulary progression, and audio exercises. |
| **ChatGPT / Journaling** | Daily writing practice (handwritten or typed) with instant AI feedback. |
| **Google Meet (Solo Calls)** | Solo speaking sessions to build fluency, structure arguments, and overcome fear. |
| **Notion Template** | Centralized database for new vocabulary, expressions, and progress tracking. |
| **Media Immersion** | Passive and active exposure through movies, series, podcasts, and music. |

## 🌟 Daily & Weekly Routine

### 1. Grammar & Input (Coursebook + YouTube)
* Follow one chapter at a time from a level-appropriate textbook (B1/B2).
* Complete written exercises and listen to accompanying YouTube audio tracks.

### 2. Active Writing (ChatGPT Journal)
* Write daily journal entries about your routine, opinions, or goals.
* Prompt ChatGPT to correct mistakes and suggest more natural phrasing.

### 3. Active Speaking (Solo Google Meet)
* Start a private Google Meet call.
* Record yourself speaking on random topics for 5–10 minutes using present, past, and future tenses.
* Review recordings to identify hesitations and pronunciation gaps.

### 4. Organization (Notion)
* Log new idioms, phrasal verbs, and technical terms into your Notion template.
* Review entries weekly using spaced repetition.
